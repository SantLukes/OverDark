# Architecture Decision Records (ADR)

Cada ADR registra **uma** decisão estrutural: o contexto, o que foi decidido e as consequências. ADRs não são editados depois de aceitos. Se a decisão mudar, crie um novo ADR que *substitui* o anterior.

|---|---|---|
| [0001](0001-arquitetura-modular-sem-framework.md) | Arquitetura modular sem framework | Aceito |
| [0002](0002-dinheiro-em-centavos.md) | Dinheiro como inteiro em centavos | Aceito |
| [0003](0003-persistencia-pdo-sql-puro.md) | Persistência com PDO e migrations em SQL puro | Aceito |
| [0004](0004-logs-estruturados-psr3-proprio.md) | Logs estruturados com logger próprio sobre a interface PSR-3 | Aceito |

## Formato

Arquivo `NNNN-titulo-em-kebab-case.md` com as seções: **Status**, **Contexto**, **Decisão**, **Consequências**.
